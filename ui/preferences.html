Data

Between 3 and 32, the video ID is hashed and only that many characters are sent (privacy mode). Set 0 to send the plain video ID.

A JavaScript regular expression whose first group is the 11 character video ID, applied to the file path. Empty disables it. yt-dlp's default naming works with -([A-Za-z0-9_-]{11})\.[A-Za-z0-9]+$.
